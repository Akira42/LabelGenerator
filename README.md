# LabelGenerator
A Custom user friendly web application to edit and generate custom electric box and panels specification and warning labels

ROADMAP:

- edição de etiquetas existentes através de campos com alteração em tempo real;
- baixar a etiqueta editada em SVG ou PDF;
- deixar os campos responsivos (quebra de linha automática);
- rich text editor para os campos de texto
- dropdown para campos fixos
- impressão de vetor direta na impressora térmica Elgin L42 Pro sem perda de qualidade (com opções de tamanhos de etiquetas e pré-visualização);
- edição visual e intuitíva dos campos das etiquetas (drag and drop, click to edit etc);
- editor visual para criação de etiquetas from scratch;
